# Smart Expense Tracker

A simple menu-based expense tracker made using basic Python. This project is suitable for a first-year B.Tech student.

## Features
1. Add an expense
2. View all expenses
3. Calculate total expenses
4. Save expenses in a text file so they are available next time

## Python concepts used
- Variables
- Lists
- Dictionaries
- Functions
- While loop
- For loop
- If-elif-else
- File handling

## How to run
1. Install Python.
2. Download `expense_tracker.py`.
3. Open a terminal in the folder containing the file.
4. Run:

   `python expense_tracker.py`

5. Follow the menu shown on the screen.

The program automatically creates `expenses.txt` when the first expense is added.
